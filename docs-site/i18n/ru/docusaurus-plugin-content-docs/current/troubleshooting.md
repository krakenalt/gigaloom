# Диагностика запуска

Ошибки совместимости возвращают `reason_ids`. Они описывают проверку, которая
не прошла; это не команда отключить защиту. Исправьте причину и повторите
`--dry-run` или `probe`.

| Причина | Что это значит | Что проверить | Безопасное действие |
|---|---|---|---|
| `gateway_not_installed` | Пакет или executable `gpt2giga` не найден | `giga doctor`, способ установки GigaLoom | Переустановить `gigaloom[gpt2giga]` из опубликованного пакета |
| `gateway_incompatible` | Версия шлюза или его API не входит в поддержанное окно | Версию `gpt2giga`, вывод проверки конфигурации | Установить совместимую версию; не подменять результат проверки |
| `gateway_models_unavailable` | Шлюз не вернул корректный список моделей | Доступность `/models`, адрес и авторизацию | Исправить шлюз или учётные данные и явно обновить маршрут |
| `agent_has_no_configurable_provider_contract` | ACP-агент не умеет безопасно сменить провайдера модели | `provider_bridge.status` в `inspect` | Запустить агента с нативным провайдером без `--with` и `--model` |
| `acp_provider_adapter_version_mismatch` | Встроенный адаптер не подтверждён для этой версии агента | Версию установки и результат `probe` | Обновить или откатить агент до поддержанной версии, затем повторить `probe` |
| `acp_provider_set_rejected` | Агент отклонил выбранного провайдера модели или не подтвердил настройку | Поддерживаемый протокол и повторное чтение в `probe` | Исправить конфигурацию агента или использовать нативный запуск; не включать неподтверждённый запасной путь |
| `acp_model_selector_unavailable` | Агент принял провайдера модели, но не умеет выбрать нужную модель | Возможности выбора модели в `inspect` | Выбрать поддержанную версию агента или нативный запуск |
| `gateway_upstream_credentials_unavailable` | В текущем процессе нет учётных данных GigaChat | Переменные авторизации в том же терминале | Экспортировать учётные данные и повторить `--dry-run`; не печатать их в лог |
| `gateway_sidecar_port_busy` | Порт управляемого шлюза занят чужим процессом | Владелец порта и активные профили шлюза | Остановить известный процесс или выбрать явно настроенный внешний шлюз |
| `gateway_route_catalog_stale` | Сохранённый список моделей или возможностей устарел | Доступность шлюза и время последней проверки | Восстановить соединение и выполнить явное обновление; устаревших данных недостаточно для запуска |

Точное имя причины в конкретном JSON может быть подробнее, но безопасное
действие определяется тем же классом ошибки. Не публикуйте полный диагностический
вывод, пока не убедились, что в нём нет локальных путей или секретов.

## Быстрые проверки

### Проверить GigaLoom и агента

```sh
giga doctor
giga agent list --json
giga agent inspect AGENT_ID --json
giga agent probe AGENT_ID --json
```

### Проверить маршрут без запуска

```sh
giga --with gpt2giga --model MODEL_ALIAS --dry-run --json AGENT_ID
```

### Вернуться к нативному провайдеру модели

```sh
giga AGENT_ID
```

Этот откат не требует восстанавливать домашний конфиг агента: GigaLoom его не
изменяет. Если проблема относится к локальному сервису, резервной копии или
обновлению данных, продолжите с [руководством по эксплуатации](operations.md).
