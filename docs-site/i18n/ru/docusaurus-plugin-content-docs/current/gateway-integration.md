# Интеграция со шлюзом

{/* Release-version snippets in this file are generated by scripts/release.py. */}

GigaLoom устанавливается самостоятельно. Базовый дистрибутив не импортирует
gateway и не требует checkout его репозитория.

Установите необязательную релизную интеграцию только для Direct Chat или legacy
preset локального gateway:

```sh
uv tool install 'gigaloom[gpt2giga]==0.9.0'
```

Extra допускает стабильные `gpt2giga>=0.3.0,<0.4.0`; committed lock разрешает
точный проверенный публичный artifact. Release testing не создаёт editable
sibling dependency.

## Выбор точного route

Каноническая форма указывает immutable route до agent token. Удобная форма
должна разрешиться ровно в один route или завершиться до process spawn:

```sh
giga --route codex-gpt2giga-gigachat-2-max codex --help
giga --with gpt2giga --model GigaChat-2-Max codex
```

Глобальные options GigaLoom заканчиваются на agent token. В
`giga --model GigaChat-2-Max codex` параметр `--model` выбирает gateway route, а
в `giga codex --model o3` suffix передаётся Codex без изменений. Content-free
dry-run показывает resolution без запуска gateway, agent или provider request:

```sh
giga --with gpt2giga --model GigaChat-2-Max --dry-run --json codex
```

Unknown, stale, ambiguous, unsupported route или version drift дают видимую
ошибку. GigaLoom не переключает protocol, gateway, provider, model или agent как
fallback.

## Managed и external profiles

Профиль `external` проверяет уже запущенный gateway. Профиль `managed` использует
существующий process lease GigaLoom, при необходимости запускает точный
установленный artifact, ждёт readiness и повторно использует здоровый warm
lease. Generated config и secret references находятся только в managed root
GigaLoom; launch и cleanup не изменяют `~/.codex`, `~/.claude`, `~/.gemini` или
global provider configuration.

При изменении readiness или identity остановите admission новых launches,
проверьте preflight reason и перезапустите только owned managed lease. Удаление
artifact `gpt2giga 0.3` явно отключает эти routes и не включает legacy
local-gateway preset. Существующие sessions, runs и immutable launch receipts
остаются читаемыми.
