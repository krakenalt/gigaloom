# Действующие инструкции

Статус: принято 4 августа 2026 года.

## Контекст

Перед запуском пользователь должен видеть, какие инструкции проекта могут
повлиять на работу агента. GigaLoom уже собирает сведения о контексте через
Context Manifest и Context Lens. Если формировать ещё один общий запрос,
инструкции могут попасть в модель дважды, а порядок их применения будет
отличаться от поведения нативного CLI.

## Решение

### Сводка только для чтения

Effective Instructions — это представление данных Context Manifest и Context
Lens только для чтения. Поиск инструкций ограничен корнем проекта,
отслеживаемыми файлами, безопасными символическими ссылками, правилами
игнорирования и пределами на количество и размер файлов.

В сводку могут входить:

- корневые и вложенные файлы `AGENTS.md`;
- файлы и селекторы профиля агента;
- правила GigaLoom;
- проектные правила нативного CLI, если адаптер явно умеет их обнаруживать без
  чтения личного домашнего каталога пользователя.

GigaLoom не объединяет автоматически правила `.cursor`, `.claude`, `.codex`,
`GEMINI.md`, `AGENTS.md` и собственные правила. Система также не копирует эти
файлы и не добавляет их в запрос модели. Глобальные настройки и домашние
каталоги нативных CLI не читаются и не изменяются.

### Формат данных

Для каждого источника сводка содержит путь и тип, контрольную сумму, область
действия, приоритет, причину включения или пропуска, актуальность, оценку
числа токенов, найденные конфликты и подсистему, которая фактически добавляет
инструкцию в запрос.

Общая часть сводки содержит редакции, контрольные суммы, количество найденных
источников, применённые ограничения и список пропусков. Текст инструкций по
умолчанию не сохраняется.

Порядок применения сообщает адаптер соответствующего агента. GigaLoom не
придумывает общий порядок для разных провайдеров. Конфликт показывается
пользователю как факт и не разрешается автоматическим слиянием. Неподдерживаемый
источник отмечается явно.

Решение, которое зависит от неизвестной или устаревшей редакции данных,
блокируется до повторной проверки. В интерфейсе устаревшие сведения можно
показывать только вместе с их редакцией и списком пропусков.

## Миграция и откат

Сводка дополняет существующие данные и не создаёт отдельную копию инструкций.
При обновлении можно пересчитать контрольные суммы, но нельзя переписывать
исходные файлы. Откат удаляет только производный кеш Context Manifest и
Context Lens. Файлы проекта и домашние каталоги CLI остаются без изменений.

## Последствия

Перед запуском пользователь видит область действия инструкций, их порядок,
конфликты, изменения и пропуски. При этом GigaLoom не меняет собственный
механизм загрузки инструкций каждого агента и не добавляет их в запрос
повторно.
