# Документация GigaLoom

{/* Release-version snippets in this file are generated by scripts/release.py. */}

GigaLoom — локальная панель управления для coding-агентов. Запускайте нативный
CLI, устанавливайте ACP-агентов или работайте в браузере, сохраняя проекты,
worktree, подтверждения и данные на своём компьютере.

Линия `0.9.0` — актуальный стабильный релиз.

## С чего начать

1. [Установите GigaLoom](installation.md).
2. Пройдите два сценария [быстрого старта](quickstart.md).
3. [Установите и проверьте агента](agent-runtimes.md).
4. Подключите поддержанный агент к [gpt2giga](gateway-integration.md).
5. Используйте [таблицу диагностики](troubleshooting.md), если маршрут
   заблокирован.

Базовый пакет не требует checkout исходников `gpt2giga`. Нативные CLI сами
владеют авторизацией. GigaLoom управляет локальным запуском и не меняет домашние
каталоги агентов, когда применяет поддержанную временную конфигурацию шлюза.
