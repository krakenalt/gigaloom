# GigaLoom documentation

{/* Release-version snippets in this file are generated by scripts/release.py. */}

GigaLoom is a local control plane for coding agents. Start a native CLI, install
an ACP agent, or use the browser interface while keeping projects, worktrees,
approvals, and stored state under local control.

The current `0.9.0` line is the latest stable release.

## Start here

1. [Install GigaLoom](installation.md).
2. Complete the two [Quickstart](quickstart.md) scenarios.
3. [Install and inspect an agent](agent-runtimes.md).
4. Connect a supported agent to [gpt2giga](gateway-integration.md).
5. Use [Launch troubleshooting](troubleshooting.md) when a route is blocked.

The base distribution does not require a `gpt2giga` source checkout. Native
agent CLIs own their authentication. GigaLoom owns local orchestration and does
not modify native agent homes when applying a supported temporary gateway
configuration.
